# 豆包小说拆解模板 · 通用合集（8 套完整模板）

> **用途：** 把任意小说粘贴给豆包，按模板一键拆解，得到结构化分析。
> **使用方法：** 选一套模板 → 复制全文 → 粘贴到豆包 → 再粘贴小说正文（或分段粘贴）→ 豆包按模板输出。
> **八套风格速选：**

| 模板 | 风格定位 | 适合场景 | 输出特点 | 一句话区别 |
|---|---|---|---|---|
| ① 严谨分析型 | 学术严谨、因果深挖 | 深度研读、改编评估、论文/复盘 | 长（3000-5000 字），表格化 | 讲透「为什么这样写」 |
| ② 速记型 | 极简速记、要点直给 | 快速通读、手机备忘、开会/讨论前复习 | 短（800-1500 字），符号化 | 5 分钟看完「这本书讲了啥」 |
| ③ 写作参考型 | 技法导向、拿来即用 | 写作学习、改编参考、拆解爆款套路 | 中（2000-3000 字），步骤化 | 讲清「怎么写才能抄」 |
| ④ 短剧改编型 | 分集导向、钩子密度 | 竖屏短剧开拍 | 分集方案 + 付费卡点 | 讲清「哪一集怎么拍」 |
| ⑤ 漫剧分集型 | 分话导向、视觉化 | 漫剧直接制作 | 分话方案 + 分镜要点 | 讲清「哪一话怎么画」 |
| 题材定制版 A：玄幻 | 境界体系、战力标尺 | 玄幻/仙侠/洪荒 | 升级链 + 越级战 | 玄幻专属字段拆解 |
| 题材定制版 B：言情 | CP 线、甜虐节奏 | 古言/现言/甜宠/虐恋 | 情感线 + 甜点/虐点 | 言情专属字段拆解 |
| 题材定制版 C：悬疑 | 线索链、反转结构 | 推理/恐怖/灵异/刑侦 | 案件链 + 反转点 | 悬疑专属字段拆解 |

> **长篇小说喂给豆包的技巧：** 豆包单次上下文有限，长篇不要一次全贴。推荐分 3 次：
> 1. 先贴「小说简介+目录+前 3 章」→ 让豆包建框架；
> 2. 再分段贴「中间章节摘要」→ 让豆包补主线/支线；
> 3. 最后贴「高潮+结局章节」→ 让豆包补爽点/伏笔/结局。
> 每段都用同一套模板的「分段拆解」指令续写即可。

---

## 通用说明：8 个模块是什么

8 套模板都包含以下 8 个模块（顺序固定，方便横向对比）：

1. **基础信息**（书名、题材、字数）
2. **一句话故事概括**
3. **核心主线与支线梳理**
4. **主要人物及其动机与成长弧线**
5. **世界观设定要点**
6. **剧情结构拆解**（开端、发展、高潮、结局）
7. **爽点与伏笔标注**
8. **可复用的写作技巧总结**

每个模块在模板里都包含：**【填写说明】**（告诉豆包怎么填）+ **【通用示例】**（示范填法，套用时删掉示例、只留格式）。

# 模板 ①：严谨分析型

> **风格特征：** 正式书面语、表格化、因果链完整、标注证据（章节/情节）、区分事实与推断。适合需要深度和准确度的场景。
> **豆包指令头（复制时保留）：**

```text
你是一名严谨的小说分析师。请严格按照下方【模板①·严谨分析型】的 8 个模块，对我提供的小说文本进行拆解。
要求：
1. 严格按模块顺序输出，不要增删模块，不要合并模块；
2. 每个模块内先给结论，再给依据（标注章节或情节位置，如“第X章/开篇/高潮段”）；
3. 区分【原文事实】与【合理推断】，推断必须标注“推断”；
4. 语言正式、客观，不使用口语和情绪化表达；
5. 若小说文本不完整，缺失处标注【文本未提供，无法判断】，不要编造；
6. 输出使用 Markdown 标题层级（三级标题为模块），表格优先于长段落。
小说文本如下：
【在此粘贴小说正文/简介/目录】
```

## 模块 1：基础信息

**【填写说明】**
- 书名：填正式书名（含卷名/部名，如有）。
- 题材：填一级题材 + 二级标签（如：玄幻·东方玄幻 / 都市·都市异能 / 言情·古言甜宠）。
- 字数：填总字数或章节数；若文本未提供，填“未提供”并注明估算依据（如“按X章×约X字估算”）。
- 作者/平台/连载状态：如文本中有则填，无则标注未提供。
- 拆解范围：注明本次拆解覆盖的章节范围（如“全书/前30章/指定片段”）。

**【通用示例】**

| 项目 | 内容 |
|---|---|
| 书名 | 《青云剑》（示例小说） |
| 题材 | 玄幻 · 东方玄幻、少年热血 |
| 字数 | 约 180 万字 / 共 620 章（示例） |
| 作者/平台 | 示例作者 / 示例平台 |
| 连载状态 | 已完结 |
| 拆解范围 | 全书（示例） |

## 模块 2：一句话故事概括

**【填写说明】**
- 用 1 句话（不超过 60 字）概括全书：主角 + 核心困境 + 核心行动 + 终极目标。
- 句式参考：`[主角]在[困境]下，凭借[关键能力/机缘]，历经[关键阶段]，最终[结局状态]。`
- 必须包含：主角身份、最大冲突、最终结果；不要剧透细节过程。
- 若为群像/多主角，概括时注明主线人物。

**【通用示例】**

> 示例：《青云剑》讲述少年剑修沈砚在宗门覆灭、家传剑断的困境下，凭借残剑中封存的剑灵传承，历经秘境试炼与正魔大战，最终以一剑重开青云宗、守护苍生的故事。

## 模块 3：核心主线与支线梳理

**【填写说明】**
- 主线：用 3-5 个节点概括（起因→推进→转折→高潮→结局），每个节点标注章节范围。
- 支线：每条支线单独列出（支线名、涉及人物、与主线的关系、结局）。
- 标注主线与支线的交汇点（如“支线X在第X章汇入主线”）。
- 若支线未完结，标注“未完结/烂尾（推断）”。

**【通用示例】**

**主线（沈砚复宗线）：**
1. 起因（第1-30章）：宗门覆灭，沈砚携断剑逃亡，获得剑灵传承（原文事实）。
2. 推进（第31-200章）：秘境试炼，修复断剑，结识伙伴（原文事实）。
3. 转折（第201-400章）：发现宗门覆灭真相与剑灵身世（原文事实）。
4. 高潮（第401-580章）：正魔大战，沈砚以残躯迎战魔尊（原文事实）。
5. 结局（第581-620章）：重开青云宗，剑灵消散，沈砚独守剑峰（原文事实）。

**支线：**
- 支线A·师妹复仇线（林小满）：为兄报仇→发现兄长另有隐情→放下仇恨加入主线（第80-350章汇入主线）。
- 支线B·魔尊身世线：魔尊实为前代宗主之子→第500章揭晓→推动高潮（推断：作者有意呼应主线“传承”主题）。
- 支线C·剑灵前世线：剑灵为上代剑宗之主→第450章揭晓→解释断剑来历。

## 模块 4：主要人物及其动机与成长弧线

**【填写说明】**
- 主要人物限定 3-5 人（主角 + 核心配角 + 关键反派）。
- 每人固定包含 5 项：身份标签、表层动机（人物自述的目标）、深层动机（推断的真实驱动）、关键抉择（2-3 个转折点）、成长弧线（起点状态→终点状态，一句话对比）。
- 成长弧线必须写成“从A到B”的对比句。
- 动机区分“人物以为的动机”与“实际驱动”，后者标注（推断）。

**【通用示例】**

**沈砚（男主）**
- 身份标签：青云宗遗孤、断剑剑修
- 表层动机：修复断剑，重开宗门
- 深层动机（推断）：证明自己不是“废物”，走出宗门覆灭的愧疚
- 关键抉择：① 秘境中放弃疗伤机会救伙伴；② 得知真相后选择放下仇恨；③ 大战中以残躯换剑灵自由
- 成长弧线：从隐忍自卑的逃亡少年 → 敢于承担苍生的剑宗之主

**林小满（女主/核心配角）**
- 身份标签：敌对宗门弟子、刺客
- 表层动机：为兄报仇
- 深层动机（推断）：渴望被认可，证明自己不弱于兄长
- 关键抉择：① 刺杀沈砚失败；② 发现兄长真相后动摇；③ 转而守护沈砚
- 成长弧线：从偏执的复仇者 → 敢于直面真相的同行者

**魔尊（反派）**
- 身份标签：魔道之主、前代宗主之子
- 表层动机：夺取剑灵传承，统领正魔
- 深层动机（推断）：向正道证明“魔道亦有传承”，为父正名
- 关键抉择：① 屠宗夺剑；② 发现剑灵真相后犹豫；③ 大战中败于沈砚
- 成长弧线：从极端的复仇者 → 败于传承的真正含义（推断）

## 模块 5：世界观设定要点

**【填写说明】**
- 只提炼“影响剧情的设定”，不罗列无关背景。
- 固定 5 类：力量体系、势力格局、社会规则、核心道具/地点、设定代价/限制。
- 每条设定标注“首次出现章节”与“剧情作用”（一句话）。
- 若设定前后矛盾，单独标注【设定矛盾】。

**【通用示例】**

| 设定类别 | 要点 | 首次出现 | 剧情作用 |
|---|---|---|---|
| 力量体系 | 练气→筑基→金丹→元婴→化神，剑修以剑意为核心 | 第5章 | 决定战力标尺与升级节奏 |
| 势力格局 | 正道五宗 vs 魔道三宫，青云宗已覆灭 | 第1章 | 沈砚孤身复宗的阻力来源 |
| 社会规则 | 剑修一生只能认一主剑，断剑不可续 | 第12章 | 制造“断剑”困境与破局点 |
| 核心道具 | 断剑“青云”内封存剑灵 | 第3章 | 全书最大机缘与伏笔载体 |
| 设定代价 | 剑灵传承每次使用消耗剑灵寿元 | 第60章 | 逼主角在“变强”与“守护”间抉择 |

## 模块 6：剧情结构拆解（开端、发展、高潮、结局）

**【填写说明】**
- 严格按四段拆解，每段包含：章节范围、核心事件（3-5 个）、情绪基调、段落功能（一句话）。
- 开端：交代主角处境、核心冲突、入局契机。
- 发展：冲突升级、支线展开、主角能力/地位变化。
- 高潮：全书最大冲突、主角终极抉择、伏笔集中回收。
- 结局：冲突解决方式、人物归宿、主题落点。
- 每段末尾标注“段落功能”（如：立人设/埋钩子/回收伏笔）。

**【通用示例】**

**开端（第1-30章）· 情绪：绝境**
- 核心事件：宗门覆灭→沈砚携断剑逃亡→秘境中获得剑灵传承→立下复宗之誓
- 段落功能：立人设（隐忍+重情）、埋核心钩子（断剑为何能传灵）

**发展（第31-400章）· 情绪：热血+波折**
- 核心事件：秘境试炼修复断剑→结识林小满→发现宗门覆灭真相→剑灵身世初露
- 段落功能：升级打怪、支线铺垫、层层加码（真相越挖越深）

**高潮（第401-580章）· 情绪：悲壮+燃**
- 核心事件：正魔大战→魔尊身份揭晓→沈砚以残躯换剑灵自由→剑灵消散
- 段落功能：集中回收伏笔、主角终极抉择、情绪顶点

**结局（第581-620章）· 情绪：释然**
- 核心事件：重开青云宗→沈砚独守剑峰→林小满接任掌门→剑峰种下青云树
- 段落功能：交代归宿、主题落点（传承不是夺取，而是守护）

## 模块 7：爽点与伏笔标注

**【填写说明】**
- 爽点：每条标注“位置（章节）+ 类型（打脸/逆袭/揭秘/收徒/升级等）+ 情绪效果（一句话）”。
- 伏笔：每条标注“埋设位置 + 回收位置 + 伏笔内容（一句话）”。
- 爽点与伏笔分开列表，不要混写。
- 至少标注 5 个爽点、5 个伏笔；若文本不足，标注【文本未提供】。

**【通用示例】**

**爽点：**
1. 第45章·逆袭爽：沈砚以练气境击败筑基境长老，众人震惊（情绪：扬眉吐气）。
2. 第120章·揭秘爽：断剑传灵之谜揭晓，原来剑灵在等有缘人（情绪：恍然大悟）。
3. 第260章·打脸爽：林小满当众承认沈砚是“真正的剑修”（情绪：解气）。
4. 第480章·升级爽：沈砚剑意大成，一剑破魔阵（情绪：热血沸腾）。
5. 第580章·情感爽：剑灵消散前说“这一生，值了”（情绪：催泪+释然）。

**伏笔：**
1. 埋设第3章 → 回收第120章：断剑裂纹中藏有剑灵（内容：断剑非凡）。
2. 埋设第12章 → 回收第500章：“断剑不可续”实为剑灵设下的考验（内容：规则反转）。
3. 埋设第80章 → 回收第350章：林小满兄长的遗物指向真相（内容：复仇线反转）。
4. 埋设第200章 → 回收第580章：剑灵每次出手都会变弱（内容：代价伏笔）。
5. 埋设第400章 → 回收第620章：青云树种子（内容：传承延续）。

## 模块 8：可复用的写作技巧总结

**【填写说明】**
- 只总结“可迁移到其他小说”的技巧，不复述剧情。
- 每条技巧固定格式：技巧名 + 适用场景 + 操作步骤（3 步内）+ 本书例证（章节）。
- 至少 5 条，覆盖：开篇、人物、冲突、伏笔、节奏五类。
- 避免空泛评价（如“文笔好”），必须写成可执行步骤。

**【通用示例】**

1. **技巧：断物开局立困境**（开篇类）
   - 适用场景：主角开局即绝境，需要快速立人设。
   - 操作步骤：① 用一件“断裂之物”象征主角困境；② 开篇 3 章内让该物获得“异象”；③ 用异象引出全书主线。
   - 本书例证：第1-3章断剑+剑灵异象。

2. **技巧：规则反转埋长线伏笔**（伏笔类）
   - 适用场景：需要 200 章后回收的大伏笔。
   - 操作步骤：① 前期立下看似铁定的规则；② 中期用细节暗示规则有例外；③ 后期揭晓规则本身是考验。
   - 本书例证：“断剑不可续”→第500章反转。

3. **技巧：代价式升级**（冲突类）
   - 适用场景：主角变强太快，需要制衡。
   - 操作步骤：① 每次升级绑定一个代价（寿元/记忆/关系）；② 代价在高潮时集中爆发；③ 让主角在“变强”与“守护”间二选一。
   - 本书例证：剑灵寿元消耗→第580章抉择。

4. **技巧：敌对转同行**（人物类）
   - 适用场景：需要一个亦敌亦友的长期配角。
   - 操作步骤：① 给配角一个与主角对立的表层动机；② 用一个真相让其动摇；③ 让其在关键战役中倒戈。
   - 本书例证：林小满复仇→倒戈。

5. **技巧：物象收尾点题**（结局类）
   - 适用场景：结局需要升华主题。
   - 操作步骤：① 开篇用一个物象象征困境；② 结局让同一物象以“新生”状态出现；③ 用一句话点出主题。
   - 本书例证：断剑→青云树种子。

# 模板 ②：速记型

> **风格特征：** 极简、符号化、要点直给、无废话。适合快速通读、手机阅读、讨论前复习。输出短，但信息密度高。
> **豆包指令头（复制时保留）：**

```text
你是一名速记员。请按下方【模板②·速记型】对我提供的小说做速记拆解。
要求：
1. 严格按 8 个模块输出，每个模块用一句话或 3-5 个短语，不写长段落；
2. 能用符号就用符号（→ / + / =），能用短语就不用整句；
3. 只记结论和关键词，不记过程细节；
4. 每个模块标题用【】包裹，模块之间空一行；
5. 若信息缺失，直接写“无/未提供”，不要编造；
6. 总字数控制在 1500 字以内。
小说文本如下：
【在此粘贴小说正文/简介/目录】
```

## 模块 1：基础信息

**【填写说明】**
- 一行写完：书名｜题材｜字数｜状态｜范围。
- 题材只写 2 个标签；字数写约数即可。
- 不确定的写“？”，不要猜。

**【通用示例】**

> 【基础信息】《青云剑》｜玄幻·热血｜约180万字｜已完结｜全书速记

## 模块 2：一句话故事概括

**【填写说明】**
- 1 句话，30 字内，公式：`[主角]+[困境]→[行动]→[结局]`。
- 只记主线，不记支线。

**【通用示例】**

> 【一句话概括】沈砚（宗门遗孤）→ 断剑+剑灵 → 秘境/大战 → 重开青云宗

## 模块 3：核心主线与支线梳理

**【填写说明】**
- 主线：用 3 个箭头短语串起来（起因→转折→结局）。
- 支线：每条 1 行：支线名+人物+结局（10 字内）。
- 支线超过 3 条只记最重要的 3 条。

**【通用示例】**

> 【主线】宗门灭→得剑灵→查真相→正魔大战→复宗
> 【支线1】林小满复仇→真相→倒戈
> 【支线2】魔尊身世→揭晓→推动大战
> 【支线3】剑灵前世→揭晓→解释断剑

## 模块 4：主要人物及其动机与成长弧线

**【填写说明】**
- 每人 1 行，格式：`名字（身份）｜动机：X｜弧线：从A→B`。
- 只记 3 人；动机只记 1 个关键词；弧线只记起点→终点。

**【通用示例】**

> 【人物】
> 沈砚（遗孤剑修）｜动机：复宗+证明自己｜弧线：自卑逃亡→剑宗之主
> 林小满（敌方刺客）｜动机：报仇→被认可｜弧线：偏执→同行者

## 模块 5：世界观设定要点

**【填写说明】**
- 5 个短语，每行 1 个：力量/势力/规则/道具/代价。
- 每行格式：`类别：要点（作用）`，10 字内。

**【通用示例】**

> 【世界观】
> 力量：剑意为核（定战力）
> 势力：正道五宗 vs 魔道三宫（主角孤立）
> 规则：断剑不可续（困境）
> 道具：断剑藏剑灵（最大机缘）

## 模块 6：剧情结构拆解（开端、发展、高潮、结局）

**【填写说明】**
- 每段 1 行：`段名（章节）：3 个关键词`。
- 关键词用“+”连接，不写完整句子。

**【通用示例】**

> 【结构】

> 高潮（401-580）：大战+揭晓+抉择

## 模块 7：爽点与伏笔标注

**【填写说明】**
- 爽点：每条 1 行：`章节+类型+情绪词`（8 字内）。
- 伏笔：每条 1 行：`埋设→回收：内容`（10 字内）。
- 各记 5 条，多了合并。

**【通用示例】**

> 【爽点】
> 45章·逆袭·扬眉吐气
> 120章·揭秘·恍然大悟
> 260章·打脸·解气

> 580章·催泪·释然

> 80章→350章：兄长遗物指真相
> 200章→580章：出手变弱

## 模块 8：可复用的写作技巧总结

**【填写说明】**
- 每条 1 行：`技巧名：3 步短语`。
- 只记 5 条，覆盖开篇/人物/冲突/伏笔/结局。
- 不写例证（速记版省略，方便背）。

**【通用示例】**

> 【技巧】

## 模块 2：一句话故事概括

**【填写说明】**
- 在一句话概括基础上，补一句**“卖点句”**：这本书最吸引人的 1 个标签（如“断剑传灵”“复仇反转”）。

**【通用示例】**

> 概括：沈砚携断剑逃亡，获得剑灵传承，历经大战重开青云宗。
> 卖点句：卖点是“断剑传灵+代价升级”，每一次变强都要付出代价，天然带钩子。

## 模块 3：核心主线与支线梳理

**【填写说明】**
- 主线按“钩子链”拆：每个节点标注“钩子是什么”（悬念/冲突/反转）。
- 支线标注“支线功能”（铺垫/误导/情感/世界观）。
- 最后给一句“改编取舍建议”（改短剧/漫剧时保留哪条、砍掉哪条）。

**【通用示例】**

**主线钩子链：**
1. 断剑为何能传灵？（悬念钩子）→ 2. 宗门覆灭真相是什么？（揭秘钩子）→ 3. 剑灵每次出手为何变弱？（代价钩子）→ 4. 魔尊与宗门有何渊源？（反转钩子）→ 5. 沈砚能否复宗？（终极钩子）

**支线功能：**
- 林小满线：情感线+误导线（先当敌人，后当同伴）
- 魔尊身世线：世界观线+高潮引爆器
- 剑灵前世线：设定解释器

**改编取舍建议：** 改竖屏短剧保留主线+林小满线，剑灵前世线压缩为 1 集揭秘；改漫剧保留剑灵视觉奇观，砍掉支线B的设定说明。

## 模块 4：主要人物及其动机与成长弧线

**【填写说明】**
- 每人拆成“人设公式”：`标签×标签 = 人设`（如：遗孤×断剑×重情）。
- 动机拆成“表层目标 + 深层伤口”（伤口是人物最痛的过去）。
- 成长弧线标注“弧线拐点”（人物改变的关键事件）。
- 最后给“人设复用提示”（如何把该人设移植到新小说/短剧）。

**【通用示例】**

**沈砚**
- 人设公式：遗孤 × 断剑 × 重情 = 隐忍但重情的少年剑修
- 表层目标：复宗；深层伤口：宗门覆灭的愧疚（觉得是自己没能守住）
- 弧线拐点：第200章得知真相后，从“自责”转为“担当”
- 复用提示：把“断剑”换成“断簪/断刀”，保留“物+伤口+担当”结构即可移植

**林小满**
- 人设公式：刺客 × 偏执 × 渴望被认可 = 亦敌亦友的女性配角
- 表层目标：报仇；深层伤口：兄长之死+被兄长光环掩盖
- 弧线拐点：第350章发现兄长真相
- 复用提示：适合短剧“女二倒戈”桥段，动机从“报仇”换成“夺位/夺宠”同样成立

**魔尊**
- 人设公式：魔尊 × 前代之子 × 为父正名 = 有悲剧感的反派
- 表层目标：夺传承；深层伤口：父辈被正道污名化
- 弧线拐点：第500章得知剑灵真相
- 复用提示：反派不要只写“坏”，给其一个“正当性伤口”，观众才会共情

## 模块 5：世界观设定要点

**【填写说明】**
- 每条设定拆成“设定 + 写法 + 复用”三列：设定是什么、作者怎么用它制造剧情、我怎么复用。

| 剑灵传承耗寿元 | 每次升级都让剑灵变弱，制造紧迫感 | 给金手指加“电量条”，用完即止 |

## 模块 6：剧情结构拆解（开端、发展、高潮、结局）

**【填写说明】**

- 标注每段的“钩子密度”（每 X 章一个钩子）。
- 最后给“结构复用模板”（一句话公式）。

**【通用示例】**

**开端（1-30章）**
- 事件：灭门→逃亡→传灵→立誓
- 写法：断物开局+异象引线
- 节奏：快（3章一个钩子）

**发展（31-400章）**
- 事件：试炼→真相→身世
- 写法：升级打怪+支线铺垫
- 节奏：中（10章一个小钩子，50章一个大钩子）

**高潮（401-580章）**
- 事件：大战→揭晓→抉择
- 写法：伏笔集中回收+代价爆发
- 节奏：快（5章一个高潮点）

**结局（581-620章）**
- 事件：复宗→消散→种树
- 写法：物象收尾+主题点题
- 节奏：慢（情绪收尾）

**结构复用模板：** 断物立困境（30章）→ 升级+揭秘（370章）→ 代价大战（180章）→ 物象收尾（40章）

## 模块 7：爽点与伏笔标注

**【填写说明】**
- 爽点拆成“爽点类型 + 铺垫手法 + 释放方式”：作者如何铺垫、如何释放。
- 伏笔拆成“伏笔物 + 伪装手法 + 回收方式”：作者如何伪装、如何回收。
- 每条最后给“复用提示”（我怎么写同款）。

**【通用示例】**

**爽点拆解：**
1. 第45章逆袭爽：铺垫（沈砚被轻视3章）→ 释放（一剑击败长老）→ 复用：先被轻视3章，再一招反杀。
2. 第580章催泪爽：铺垫（剑灵变弱200章）→ 释放（消散前一句话）→ 复用：代价铺垫越长，释放越催泪。

**伏笔拆解：**
1. 断剑裂纹：伪装（当作普通裂纹）→ 回收（120章揭晓藏灵）→ 复用：把伏笔藏在“不起眼细节”里。
2. “断剑不可续”：伪装（当作世界规则）→ 回收（500章反转为考验）→ 复用：用规则当伏笔，回收时反转规则。

## 模块 8：可复用的写作技巧总结

**【填写说明】**
- 每条技巧固定格式：**技巧名｜什么时候用｜3步操作｜本书例证｜改编提示**。
- 至少 5 条，覆盖开篇/人物/冲突/伏笔/节奏/结局。
- 改编提示必须具体到短剧/漫剧的某一集或某一镜。

**【通用示例】**

1. **断物开局**｜开局绝境时用｜①选一件断裂之物 ②3章内给异象 ③引出主线｜例证：第1-3章｜改编提示：漫剧第1集只拍断剑异象，不解释，留钩子。
2. **规则反转**｜需要长线伏笔时用｜①立铁律 ②埋例外细节 ③后期反转｜例证：“不可续”→500章｜改编提示：短剧第10集用一句话暗示例外。
3. **代价升级**｜金手指太强时用｜①升级绑代价 ②高潮爆发 ③二选一抉择｜例证：剑灵寿元｜改编提示：漫剧每集让剑灵“闪一下”表示消耗。
4. **敌转友**｜需要长期配角时用｜①对立动机 ②真相动摇 ③关键倒戈｜例证：林小满｜改编提示：短剧第15集安排倒戈战。
5. **物象收尾**｜结局升华时用｜①困境物象 ②新生物象 ③点题一句｜例证：断剑→青云树｜改编提示：漫剧最后一镜只拍青云树，不说台词。

## 组合玩法（进阶）

单套模板之外，8 套可以两两组合，按需求串着用：

1. **看懂一本书**：② 速记型（5 分钟抓全貌）→ ① 严谨分析型（深挖逻辑）；
2. **学写作**：③ 写作参考型（提炼技法）→ 题材定制版（补齐题材专属字段，如玄幻的境界/战力）；
3. **改短剧**：② 速记型（先定卖点）→ ④ 短剧改编型（出分集方案），玄幻/言情/悬疑书可再叠一层题材定制版补专属爽点；
4. **改漫剧**：① 严谨分析型（评估改编价值）→ ⑤ 漫剧分集型（出分话分镜方案）；
5. **通用+题材叠加**：先用④/⑤做整体分集，再用题材定制版深挖某一模块（如玄幻的境界体系表）填进对应模块位置。

> 组合时的技巧：后一套模板直接引用前一套的输出（“基于上一步的拆解，请按模板X继续”），不用重新喂全文，省豆包上下文。

## 快速上手（3 步）

1. 选一套模板，复制其「豆包指令头 + 8 个模块」全文；
2. 粘贴到豆包，再粘贴小说文本（长篇分段喂）；
3. 豆包输出后，检查：模块是否齐全、推断是否标注、缺失处是否标注【文本未提供】。不满意就追加一句：“请按模板重新输出，补齐缺失模块，不要编造。”
