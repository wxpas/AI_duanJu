# studio/ · AI 短剧工作台（首页模板）

一个静态首页：纯 HTML + CSS + 原生 JS，没有框架和构建步骤，不请求任何后端或第三方资源（唯一的外链是「打开豆包」）。

## 来源说明（请先看）

这个页面是**从零写的，不是 liblib.tv（LibTV）的源码镜像**。里面没有它的代码、Logo、图片或用户作品。

- 参考的只有它首页的板块类型（顶部活动条 → 创作入口 → 作品精选）和「黑底 + 青蓝」的色调方向；版式和功能是按本仓库的漫剧教程另行设计的，和原站并不一样（从 2026 年 3 月前后的公开截图看，原站没有侧边栏，首屏是轮播加「开始创作」按钮，下面是横版卡片网格；它现在的版式可能又变了）。
- 图片：10 张作品封面是 AI 生成的原创插画；另外 3 张封面和 8 张流程配图取自本仓库 `tutorial/assets/`。
- 作品标题、作者、点赞数、播放数全部是虚构的示例数据。
- 「生成提示词」只是在浏览器里把教程附录 D1–D7 的模板和你填的内容拼起来，不调用任何 AI 接口。
- 「预览」是用封面图做的 8 秒推 / 拉 / 摇镜头动效加字幕，不是真正的视频。

## 预览

页面里有指向 `../tutorial/` 和 `../novel-templates/` 的链接，所以从**仓库根目录**起服务：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/studio/
```

直接双击 `index.html`（`file://`）也能用。

## 目录

```
studio/
├── index.html      页面结构，图标是内联 SVG
├── css/style.css   全部样式（按 01–14 分节，第 01 节是配色和尺寸变量）
├── js/data.js      所有内容：下拉选项、7 种提示词模板、30 天计划、筛选项、作品列表
├── js/app.js       交互逻辑
└── assets/         favicon、流程配图 steps/、作品封面 works/（弹层用的大图在 works/large/）
```

## 常见修改

| 想改什么 | 改哪里 |
|---|---|
| 作品、筛选项、提示词模板、推荐语 | `js/data.js`（`works` / `filters` / `modes` / `options`），不用动 `app.js` |
| 配色 | `css/style.css` 第 01 节的变量。内置一套粉紫预设：给 `<html>` 加上 `data-accent="pink"` |
| 顶部倒计时 | `index.html` 里 `#announce` 的 `data-days`（从第一次打开起算），或加 `data-deadline="2026-12-31T23:59:59+08:00"` 改成固定截止时间 |
| 接真实接口 | `js/app.js` 的 `requestPrompt()`（生成提示词）和 `fetchPage()`（作品分页）现在是「本地数据 + 人为延迟」，换成 `fetch` 即可 |

浏览器里保存的内容都在 `localStorage` 的 `duanju:*` 下（主题、侧边栏、上次的输入、排序、点赞、计划开始日期），清掉即恢复初始状态；提示条「已关闭」记在 `sessionStorage`，重开标签页会再出现。

快捷键：`/` 聚焦搜索，`Ctrl/⌘ + Enter` 生成；预览弹层里 `← →` 切换、空格播放 / 暂停、`Esc` 关闭，浏览器「后退」也会关闭弹层。

## 验证情况

- 只在无头 Chromium 153 里做过自动化检查：320–1920 px 各宽度无横向溢出；深 / 浅色各抽查 66 组文字与背景的配色，正文对比度不低于 4.5:1（大标题不低于 3:1）；生成器、筛选 / 排序 / 搜索 / 加载更多、点赞、弹层（键盘、触摸滑动、后退、深链）、抽屉菜单；`file://` 直接打开。
- **没有**在真实的 Safari、Firefox、iOS、Android 设备上测过。
- 已知的小限制：切换主题的圆形揭示动画进行中（约 0.5 秒），页面不响应点击，这是 View Transitions 的默认行为。
