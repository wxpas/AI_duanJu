# 原创漫剧成片说明

这是根据本次对话原创底稿制作的三集漫剧，不是分享链接中原剧的视频。最终形式为竖屏定格漫剧：角色配音、字幕、画面推拉和合成音效，不包含逐帧角色动作或口型动画。

- `成片/诡异入侵_三集完整漫剧.mp4`：三集合辑，约96秒。
- `成片/第1集.mp4`、`第2集.mp4`、`第3集.mp4`：每集约32秒。
- `制作素材/`：配音、画面与字幕图片。
- `制作成片.py`：成片合成脚本，依赖 Python 的 pillow、numpy、imageio-ffmpeg。

字幕字体为 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk)，按 SIL Open Font License 1.1 发布。背景氛围和提示音通过脚本合成。
