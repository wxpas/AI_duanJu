# AI_duanJu · 漫剧制作零基础大白话教程

> 一句话定位：**漫剧 = 漫画的画面 + 动画的动态 + 短剧的节奏 + 配音的情绪**。
> 本仓库是一份从零开始学习漫剧制作的图文教程，适合零基础新手跟随学习。
> **工具以豆包为准：** 选题/剧本/分镜/提示词/配音稿用豆包，生图用豆包生图，剪辑动态用剪映——每个环节配图解 + 可复制提示词（附录 D1-D7）。

## 八套风格速选

| 模板 | 风格 | 适合场景 | 输出特点 |
|---|---|---|---|
| ① 严谨分析型 | 学术严谨、因果深挖 | 深度研读、改编评估 | 3000-5000 字，表格化 |
| ② 速记型 | 极简速记、要点直给 | 快速通读、手机备忘 | 800-1500 字，符号化 |
| ③ 写作参考型 | 技法导向、拿来即用 | 写作学习、改编参考 | 2000-3000 字，步骤化 |
| ④ 短剧改编型 | 分集导向、钩子密度 | 竖屏短剧开拍 | 分集方案 + 付费卡点 |
| ⑤ 漫剧分集型 | 分话导向、视觉化 | 漫剧直接制作 | 分话方案 + 分镜要点 |
| 玄幻定制版 | 境界体系、战力标尺 | 玄幻/仙侠/洪荒 | 升级链 + 越级战 |
| 言情定制版 | CP 线、甜虐节奏 | 古言/现言/甜宠/虐恋 | 情感线 + 甜点/虐点 |
| 悬疑定制版 | 线索链、反转结构 | 推理/恐怖/灵异/刑侦 | 案件链 + 反转点 |

8 套模板均包含 8 个模块：基础信息、一句话概括、主线与支线、人物动机与弧线、世界观设定、剧情结构（开端/发展/高潮/结局）、爽点与伏笔、写作技巧总结。
